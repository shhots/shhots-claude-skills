# Hook Frameworks

Ten named frameworks for the first 0-2 seconds. Pick by fit, not by habit: match the framework to what the audience already feels about the problem. Every hook must be speakable in under 2 seconds (roughly 5-8 words) and must not state any claim outside the allowed list.

## 1. Problem callout
Name the exact pain in the audience's words.
Example shape: "Your [thing] keeps [failing] by [moment]."
Fits: products solving a felt, frequent annoyance.

## 2. Before/after tease
Promise a visible transformation without stating an unallowed claim.
Example shape: "This is what [product category] looked like before I found this."
Fits: visual products (skincare, home, apparel).

## 3. Curiosity gap
Open a loop the viewer must watch to close.
Example shape: "Nobody told me this about [category]."
Fits: products with a non-obvious mechanism or use.

## 4. Social proof anchor
Lead with adoption or popularity, only if the user supplied the fact.
Example shape: "There's a reason everyone's switching to this."
Caution: numbers ("10,000 people bought this") only if user-supplied.

## 5. Negativity hook
Contradict a common belief or habit.
Example shape: "Stop [common behavior]. Here's why."
Fits: categories with an entrenched default the product replaces.

## 6. POV framing
Put the viewer inside a scene they recognize.
Example shape: "POV: it's 7am and [relatable situation]."
Fits: lifestyle-adjacent products; pairs naturally with UGC delivery.

## 7. Direct question
Ask the question the audience already asks themselves.
Example shape: "Why does [problem] keep happening?"
Fits: problem-aware audiences.

## 8. Unexpected demo
Open on the product doing something surprising, no speech needed.
Example shape: [visual: the product in an unexpected stress test or context]
Fits: products with a demonstrable physical property. The hook lives in the treatment, not the script.

## 9. Cost/effort contrast
Contrast the old way's cost or effort with the new way, using only user-supplied figures.
Example shape: "I used to [expensive/slow way]. Then this."
Fits: products replacing a service or a routine.

## 10. Myth-bust
State the myth, then break it.
Example shape: "You don't actually need [assumed necessity]."
Fits: educated audiences tired of category noise.

## Selection heuristic
Problem-aware audience: 1, 7, 9. Solution-aware: 4, 5, 10. Unaware (cold): 3, 6, 8. When testing, pick hooks from different groups so the test reads clean.
